Published

Question

Im Folgenden ist der Datensatz CASchools zu analysieren. Er ist unter dieser Quelle erhältlich: https://vincentarelbundock.github.io/Rdatasets/csv/AER/CASchools.csv.

Eine Möglichkeit, den Datensatz zu beziehen, ist diese Sammlung an Datensätzen. Suchen Sie dort nach dem Namen des Datensatzes. Importieren Sie dann die Daten in R.

Hilfe zum Datensatz ist auf dieser Webseite abrufbar.

Berechnen Sie das folgende lineare Modell:

AV: math.

UV: district.

Aufgabe: Was ist der Anteil der Posterior-Verteilung des Regressionskoeffizienten der Variable district, der außerhalb des ROPE liegt? Gehen Sie von z-standardisierten Variablen aus.

Hinweise:

Beachten Sie die Bearbeitungshinweise.

Solution

library(tidyverse)
library(easystats)

Gefragt war nach diesem Prädiktor district:

So kann man sich das ROPE berechnen lassen:

rope(mod)
Parameter CI ROPE_low ROPE_high ROPE_Percentage Effects Component
(Intercept) 0.95 -0.1 0.1 1.0000000 fixed conditional
uv1 0.95 -0.1 0.1 0.3531579 fixed conditional

Dann sucht man sich die richtige Zeile und liest den Prozentwert p ab. Dann rechnet man 1 - p und reicht das Ergebnis (als Anteil, nicht als Prozentwert) als Lösung ein.

Antwort: 0.65.

Oft ist ein Diagramm zum Verstehen hilfreich, das kann man so erhalten:

plot(rope(mod))

Wie man sieht liegt also dieser Teil außerhalb des ROPE: 0.65.

```{r}
library(tidyverse)

```

```{r}
d_name
```


Quelle: `r paste0("<", d_path, ">")`.


So sehen die ersten Zeilen des Datensatzes aus:

```{r}

```




Prädiktor(en) und AV z-transformieren:

```{r echo = TRUE}

```





Zunächst berechnet man das Modell, etwa so:



```{r mod, results = "hide", echo = TRUE}
mod <- stan_glm(av ~ uv1, 
                data = d, 
                refresh = 0,
                seed = 42)  # Reproduzierbarkeit
```



Gefragt war nach diesem Prädiktor ``r focus_pred``:



So kann man sich das ROPE berechnen lassen:

```{r echo = TRUE}
rope(mod)
```

Dann sucht man sich die richtige Zeile und liest den Prozentwert `p` ab.
Dann rechnet man `1 - p` und reicht das Ergebnis (als Anteil, nicht als Prozentwert) als Lösung ein.






```{r  eval = TRUE, echo = FALSE}
rope_df <-
  rope(mod) %>% 
  as_tibble()

inside_rope <- rope_df$ROPE_Percentage[rope_df$Parameter == "uv1"]
outside_rope <- (1 - inside_rope ) %>% round(2)

sol_raw <- outside_rope %>% round(2)
sol <- exams::fmt(sol_raw, 2)
```




**Antwort**: `r sol`.

Oft ist ein Diagramm zum Verstehen hilfreich, das kann man so erhalten:

```{r echo = TRUE, cache = FALSE, eval = FALSE}
plot(rope(mod))
```

```{r echo = FALSE, cache = FALSE, eval = FALSE}
rope_mod <- rope(mod)
plot(rope_mod, data = d)
```


Wie man sieht liegt also dieser Teil außerhalb des ROPE: `r outside_rope`.

sol_tol <- exams::num2tol(sol_raw, min = config$tol_abs, reltol = config$tol_rel) %>% exams::fmt(3)
